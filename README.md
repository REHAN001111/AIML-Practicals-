AIML Practicals – CSV Datasets

Created by: Rehan Mulani

About the Project

This repository contains CSV datasets for Artificial Intelligence and Machine Learning (AIML) practicals. These datasets are intended for educational purposes, experimentation, data analysis, and machine learning model development.

Practical List

Practical No.| Topic| Dataset File
1| Association Between Variables| "practical_01_association.csv"
2| Clustering| "practical_02_clustering.csv"
3| Principal Component Analysis (PCA)| "practical_03_pca.csv"
4| Naive Bayes Classification| "practical_04_naive_bayes.csv"
5| K-Nearest Neighbors (KNN)| "practical_05_knn.csv"
6| Linear Regression| "practical_06_linear_regression.csv"
7| SVM Regression| "practical_07_svm_regression.csv"
8| Regularization| "practical_08_regularization.csv"
9| CCTV Detection Log Analysis| "practical_09_cctv_detection_log.csv"
10| Multimodal Fake News Classification| "practical_10_multimodal_fake_news.csv"

Repository Contents

- "DATASET_GUIDE.csv" – Overview of the practical datasets, key columns, and notes.
- "practical_01_association.csv" to "practical_10_multimodal_fake_news.csv" – Dataset files for the practicals.
- "AIML_Practicals_CSV_Datasets.zip" – Compressed archive containing the datasets.

Technologies and Concepts

- Python
- Pandas and NumPy
- Data preprocessing and exploratory data analysis
- Supervised and unsupervised machine learning
- Classification and regression
- Dimensionality reduction
- Model regularization

How to Use

1. Download the repository or individual CSV files.
2. Extract the ZIP archive if necessary.
3. Open the CSV files using Python, Pandas, Microsoft Excel, or Google Sheets.
4. Use the datasets to perform the relevant AIML practicals.

Example:

import pandas as pd

df = pd.read_csv("practical_01_association.csv")
print(df.head())
print(df.info())

Dataset Disclaimer

These datasets are provided for educational and demonstration purposes. Verify the dataset structure and suitability before using it in experiments or reports. The datasets should not be assumed to represent real-world observations.
